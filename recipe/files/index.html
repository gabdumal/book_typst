Arquivos

Agora que sabemos o básico do Typst, vamos escrever um documento novo. Dessa vez, descreveremos uma receita de bolo de chocolate!

O Typst permite que um projeto tenha vários arquivos diferentes. Esses arquivos incluem imagens, anexos, e outras páginas do documento.

Novo arquivo

Seção intitulada “Novo arquivo”

Neste capítulo, vamos criar outra página dentro do mesmo projeto em que estávamos trabalhando.

Clique no botão com ícone de arquivo de documentos no menu na lateral esquerda do Typst. Na imagem, ele está destacado com uma borda azul.

Ele abrirá o menu de explorar arquivos. Por enquanto, está listado apenas o arquivo atual, o main.typ. Esse arquivo apresenta um ícone de olho aberto.

Isso significa que ele está selecionado para exibição. Portanto, seu conteúdo será renderizado no formato PDF. Apenas um arquivo pode ser selecionado por vez.

Na parte superior do menu, existem três botões principais, representados pelos seus ícones:

  • folha de papel: criar um arquivo novo em branco;
  • pasta de documentos: criar uma nova pasta vazia; e
  • seta para cima: fazer upload de um arquivo do computador para o projeto.

Clique no botão de criar um novo arquivo. Isso criará mais uma entrada da lista de arquivos em que você pode escrever o nome do novo documento.

Escreva recipe.typ e pressione EnterEnterEnterEnter. O novo arquivo será criado. Então, clique nele na lista. Agora, o editor de texto mostrará o arquivo em branco.

Contudo, esse novo arquivo ainda não está selecionado para a exibição. Sobre ele, pode-se ver um ícone de olho fechado. O PDF renderizado ainda é referente ao main.typ.

Para selecionar o arquivo recipe.typ para a exibição, pressione o ícone do olho fechado. Você verá que o PDF renderizado mudou para ficar completamente em branco.

Mas ainda tem um detalhe. Quando você seleciona um arquivo pelo ícone de olho, ele só se torna o arquivo exibido temporariamente.

Recarregue a página, e você verá que o arquivo selecionado terá voltado a ser o main.typ.

Para definir um arquivo como padrão, você precisa acessar o menu de configurações do projeto. Ele tem um ícone de engrenagem, e está localizado na parte inferior da tela na barra da lateral esquerda.

Nesse menu, procure a configuração “Export and preview”. Então, troque o arquivo main.typ selecionado pelo recém-criado recipe.typ.

Agora, abra o arquivo recipe.typ. Vamos finalmente começar a escrever.

Título

Seção intitulada “Título”

A primeira coisa de que uma receita precisa é de um título. No Typst, a forma de definir títulos é com o símbolo de igual (=). Escreva o conteúdo a seguir no documento.

Se quisermos escrever um subtítulo, bastaria usar dois símbolos de igual (=) seguidos. Veja o exemplo.

Para mais níveis, você pode usar mais repetições de =. Você pode adicionar quantos níveis quiser.

Além disso, o próprio símbolo de igual (=) é um atalho para a função #heading. Na referência dessa função você pode conferir os vários parâmetros que ela possui. Por enquanto, o mais relevante é o level, que indica o nível.

Mas, por enquanto, vamos remover tudo isso do documento recipe.typ e manter apenas o seguinte.

Imagem

Seção intitulada “Imagem”

Vamos adicionar a seguinte imagem ao documento. Baixe-a com o nome bolo.jpg.

É um costume criar uma pasta no projeto para colocar todas as imagens usadas. Abra o menu de explorar arquivos, e clique no botão de criar nova pasta. Então, nomeie-a como assets.

Agora, vamos fazer upload da imagem do bolo para o projeto. Clique no botão de fazer upload, que tem o ícone de uma seta para cima. Isso abrirá um pop-up para selecionar o arquivo.

Clique no botão “Pick a file”, e selecione o arquivo bolo.jpg da sua pasta de downloads. Então, pressione o botão “Upload file” para confirmar o envio.

Então, arraste com o mouse o arquivo bolo.jpg para dentro da pasta assets.

Agora, abra o arquivo recipe.typ.

Para adicionar uma imagem, use a função #image. Ela recebe como parâmetro principal o caminho em que a imagem está. No nosso caso, ele é /assets/bolo.jpg. Adicione o seguinte ao documento.

Essa função apresenta outros parâmetros, como descritos em sua referência. Dois muito importantes são a altura (height) e a largura (width). Essa imagem tem 1920 × 1280 px, então ela fica muito grande na página.

Vamos definir a altura como 6 centímetros, que é um tamanho mais razoável. Perceba que a largura foi automaticamente ajustada para ficar proporcional.

Se quisermos fazer um banner, podemos fazer a imagem ocupar a largura completa da página, dentro das margens. Para isso, use um valor de porcentagem no parâmetro width.

Por padrão, a imagem é cortada para se ajustar às proporções customizadas. Se preferir que a imagem seja esticada em vez de cortada, você pode usar o parâmetro fit com o valor stretch.

Por enquanto, vamos manter apenas a forma mais simples de inclusão de imagem. Apague os experimentos que fizemos.
