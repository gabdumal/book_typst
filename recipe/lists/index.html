Listas

A última seção da receita é o seu modo de preparo. Vamos usar listas numeradas e não-numeradas para apresentar os passos. Também vamos criar componentes customizados para cada tipo de instrução.

Componentes customizados

Seção intitulada “Componentes customizados”

Adicione uma linha de separação no final do documento e abra uma nova seção chamada == Modo de preparo.

Nós queremos estilizar algumas palavras-chave da receita com cores pastéis, como se fossem destacadas por marcadores de texto. Para isso, podemos utilizar a função #box, e definir o seu preenchimento por meio do atributo fill.

Para não termos que chamar a função #box e passar todos os parâmetros que ela requer o tempo todo, podemos criar uma função customizada que aplicará a cor que desejamos. Copie o código abaixo para o fim do documento.

Da mesma forma como fizemos anteriormente, nós recebemos o parâmetro padrão it e o encapsulamos por uma função. Nesse caso, é a função #box, em que definimos os atributos de cor de preenchimento e de espaçamento interno.

Todas os outros componentes customizados que usaremos funcionam de forma similar, então apenas substitua o código copiado anteriormente pelo disposto a seguir, que contém todos eles.

Crie uma subseção chamada === Preparação no fim do documento.

Contudo, a forma mais simples de elencar os passos é utilizar o atalho do símbolo de mais (+), seguido do texto do item. Você pode definir um subitem simplesmente ao digitar dois espaços antes do símbolo +.
