Customização

Agora que começamos a escrever as informações em texto da receita, podemos tratar sobre definições e customização do documento.

Texto

Seção intitulada “Texto”

O web app do Typst possui um corretor ortográfico integrado, que funciona em português. Contudo, para que ele funcione, é necessário definir o idioma do documento.

Até agora, você provavelmente viu que várias das palavras em português que escrevemos são tratados como incorretas. Nesse caso, elas são marcadas por uma linha roxa ondulada. Isto ocorre porque o corretor é configurado por padrão para funcionar em inglês.

Para definir as definições de texto, utilizamos a função #text. Ela recebe como parâmetro um bloco de texto delimitado por colchetes ([...]). Vamos fazer alguns testes com essa função. Copie o exemplo a seguir para o fim do documento.

Conforme especificado na referência da função, existem muitos parâmetros opcionais

Aquele que define o idioma é o lang. Ele recebe o código de duas letras do idioma desejado. No caso do português, o código é "pt".

Além disso, podemos especificar a região do idioma com o parâmetro region, que recebe outro código de duas letras para a variante da língua. No caso do português brasileiro, o código é "br".

Definições padrão

Seção intitulada “Definições padrão”

Nosso bloco de texto de exemplo está devidamente configurado. Mas como fazer com que todo o texto do documento use essas definições por padrão?
