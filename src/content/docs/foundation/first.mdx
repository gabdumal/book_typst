Inicialmente, [crie](http://typst.app/signup/) sua conta no web app do Typst ou [**acesse-a**](http://typst.app/signin/) se você já tiver criado.

A primeira página é a do **painel inicial**, ou _dashboard_ em inglês.
Ela lista os documentos já criados por você, e permite criar novos.
Nesta imagem, alguns documentos que eu havia escrito previamente estão listados.

Na página, podemos ver dois botões principais:

- o primeiro, chamado **_Empty document_**, é usado para criar um documento em branco, utilizando apenas as definições padrão do Typst;
- o segundo, chamado **_Start from template_**, serve para criar um documento novo já configurado e preenchido conforme um modelo à sua escolha.

## Criando um documento

**Crie** um novo documento **em branco** pelo primeiro botão.
Um _pop-up_ será exibido pedindo para você escolher um nome para o novo documento e confirmar sua criação.
Nomeie-o como "Meu primeiro documento".

## Escrevendo parágrafos

O Typst utiliza o padrão de caracteres [Unicode](https://pt.wikipedia.org/wiki/Unicode), que tem total suporte para acentos e caracteres especiais.
Dessa forma, podemos escrever a maior parte do texto em português comum.

**Escreva** o texto abaixo na seção de edição de texto.

```typst title="main.typ" frame="code"
Olá, mundo!
Este é o meu primeiro documento escrito no Typst.
Diferentemente do LaTeX, a língua portuguesa é suportada por padrão.

Será que vou gostar?
```

A **renderização** deve ficar como abaixo.
A fonte padrão do Typst é a "[Libertinus Serif](https://en.wikipedia.org/wiki/Libertinus)", no tamanho 11.
Ela tem o objetivo de ser uma alternativa de código livre à "Times New Roman".

Perceba que nosso bloco de texto foi renderizado como **dois parágrafos** sucessivos.
As três primeiras linhas escritas no bloco ficaram em um parágrafo, mas a última linha ficou em outro.

<Figure caption="Renderização da mensagem de olá.">
  <Image
    src={rendering_hello}
    alt={`Renderização do parágrafo escrito. Os primeiros trechos estão diagramados na mesma linha. Já a frase "Será que vou gostar?" está disposta em um próximo parágrafo, separado por uma quebra de linha.`}
  />
</Figure>

No Typst, um [parágrafo](https://typst.app/docs/reference/model/par/) é encerrado quando você deixa uma **linha em branco** logo após o texto.
Dentro de um mesmo bloco, você pode quebrar linhas entre cada frase da forma como quiser.
Cada quebra de linha simples vai ser interpretada apenas como um espaço.
Já uma quebra de linha dupla formará um parágrafo novo.

```typst title="main.typ" frame="code" mark={6}
// Esse bloco forma o primeiro parágrafo,
// mesmo que você tenha quebrado linhas entre cada frase.
Olá, mundo!
Este é o meu primeiro documento escrito no Typst.
Diferentemente do LaTeX, a língua portuguesa é suportada por padrão.

// Esse bloco forma o segundo parágrafo
// porque você deixou uma linha em branco logo antes dele.
Será que vou gostar?
```

Como último detalhe, você pode **quebrar uma linha** na renderização sem que ela forme um parágrafo.
Para isso, utilize o símbolo de contrabarra (`\`) no fim da frase.

Cole o trecho abaixo no documento logo abaixo da última frase, deixando uma linha em branco após ela e antes do bloco novo.

```typst title="main.typ" frame="code"
Se eu quiser exibir uma quebra de linha na renderização sem formar um parágrafo, eu posso usar o símbolo de contrabarra (`\`). \
Essa linha aparece na frase de baixo, mas não forma um parágrafo.
```

## Estilizando o texto

E se quisermos dar destaque ao nosso texto?
Caso tenha tido contato com Markdown, você sabe que podemos usar `_underscores_` para indicar que o texto deve ficar em _itálico_ ou ainda `**asteriscos duplos**` para indicar **negrito**.

No Typst, podemos utilizar esses sinais gráficos de uma forma similar.
Usamos `_underscores simples_` para deixar um trecho do texto em itálico, e usamos `*asteriscos simples*` para indicar o negrito.
Cole o trecho abaixo no documento para ver.

```typst title="main.typ" frame="code"
Nesse trecho, _este texto_ deve ficar em itálico.
Já *este texto aqui* deve ficar em negrito.
Você ainda pode _*combinar ambos*_.
```

Esses símbolos representam apenas atalhos para **funções** do Typst.
Assim como uma linguagem de programação, o Typst disponibiliza um conjunto de funções nativas e de palavras-chave, que formam a sua [sintaxe](https://typst.app/docs/reference/syntax/).

O [itálico](https://typst.app/docs/reference/model/emph/) é definido por uma função chamada "emph", enquanto o [negrito](https://typst.app/docs/reference/model/strong/) utiliza a função "strong".

Para chamar uma função do Typst, utilize o símbolo de cerquilha (`#`) e digite seu nome.
Em seguida, abra colchetes (`[...]`) e digite o conteúdo a ser formatado dentro deles.

Veja o exemplo no código abaixo.
Cole-o no documento.

```typst title="main.typ" frame="code"
Também podemos obter os efeitos de #emph[itálico],
de #strong[negrito], e de ambos #emph[#strong[juntos]]
utilizando as funções do Typst.
```

## Funções e parâmetros

Uma **função** no Typst pode receber vários **parâmetros**, e sempre retorna apenas um resultado.
A função `#strong[Conteúdo a formatar]` recebe como parâmetro dentro dos colchetes o conteúdo que se deseja formatar.

Todo o bloco dentro dos colchetes (`[...]`) conta como apenas **um parâmetro** recebido, independentemente da quantidade de palavras.
Nós podemos, inclusive, chamar uma outra função dentro dos colchetes, como fizemos no exemplo em que se usa itálico e negrito juntos.

```typst title="main.typ" frame="code"
#strong[O conteúdo a seguir ficará em #emph[itálico] também.]
```

Nesse caso, já que o o conteúdo dentro dos colchetes é o **único parâmetro** passado, o Typst não requer que nós utilizemos parênteses (`(...)`).

Mas, tecnicamente, a forma completa de chamar uma função é abrindo os **parênteses** primeiro, e abrindo os colchetes dentro deles, como no exemplo a seguir.
Desse jeito, fica bem parecido com uma linguagem de programação, né?

```typst title="main.typ" frame="code"
#strong([Conteúdo a formatar])
```

Inclusive, se você ler a [referência](https://typst.app/docs/reference/model/strong/) técnica da função `#strong`, vai perceber que ela tem um **parâmetro opcional** chamado `delta`.
Esse parâmetro controla o quão intenso será o realce do negrito.

Para usar parâmetros opcionais, escreva o nome do parâmetro dentro dos parênteses (`(...)`), digite dois-pontos (`:`) e defina o valor desejado.
Cole o exemplo abaixo no documento para entender como fazer isso.

```typst title="main.typ" frame="code"
#[Conteúdo a formatar]\
#strong(delta: 200, [Conteúdo a formatar])\
#strong(delta: 300, [Conteúdo a formatar])
```

Além disso, para melhorar a formatação, podemos deixar todos os parâmetros opcionais dentro dos parênteses (`(...)`), e colocar o bloco com os **colchetes** (`[...]`) **para fora**.

O exemplo abaixo será renderizado exatamente da mesma forma como a última linha do exemplo anterior.
As quebras de linha dentro dos colchetes serão ignoradas pelo Typst, porque são quebras de linha simples.

```typst title="main.typ" frame="code"
#strong(delta: 300)[
  Conteúdo a formatar
]
```

Esse tipo de estrutura será usado com frequência em seus documentos, porque permite que você defina os parâmetros de um bloco de texto, mas formate seu conteúdo em várias linhas, da forma como achar melhor.

Outro destaque comum é realçar trechos de **código-fonte** utilizando uma fonte **monoespaçada**.
Para fazer isso no Typst, utilize o atalho de `` `backticks` `` --- também chamado de acento grave em português (o que se usa na crase).

A função equivalente é chamada `#raw`.
Se você ler sua [referência](https://typst.app/docs/reference/text/raw/), perceberá que o parâmetro principal dela não pode ser um conteúdo arbitrário entre colchetes.
Na verdade, ela exige que você escreva um texto simples entre aspas (`"..."`), ou seja, uma _string_.
Veja o seu uso no exemplo a seguir.
Cole-o no documento.

```typst title="main.typ" frame="code"
Aqui, coloca-se `este trecho` em monoespaçado.
O #raw("mesmo resultado") pode ser obtido usando a função.
```
