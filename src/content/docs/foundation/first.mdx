Inicialmente, [crie](http://typst.app/signup/) sua conta no web app do Typst ou [**acesse-a**](http://typst.app/signin/) se você já tiver criado.

A primeira página é a do **painel inicial**, ou _dashboard_ em inglês.
Ela lista os documentos já criados por você, e permite criar novos.
Nesta imagem, alguns documentos que eu havia escrito previamente estão listados.

Na página, podemos ver dois botões principais:

- o primeiro, chamado **_Empty document_**, é usado para criar um documento em branco, utilizando apenas as definições padrão do Typst;
- o segundo, chamado **_Start from template_**, serve para criar um documento novo já configurado e preenchido conforme um modelo à sua escolha.

**Crie** um novo documento **em branco** pelo primeiro botão.
Um _pop-up_ será exibido pedindo para você escolher um nome para o novo documento e confirmar sua criação.
Nomeie-o como "Meu primeiro documento".

O web app vai abrir a página de edição de texto, com o documento vazio.
Ela é dividida em duas seções principais:

- o lado esquerdo da tela representa o **editor de texto**, em que você escreverá o documento;
- o lado direito mostra a **renderização** do seu documento no formato PDF.
