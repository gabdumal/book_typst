Mas um dos pontos-chave do Typst é sua capacidade de usar **modelos** de documentos prontos, que já carregam toda a formatação necessária.

## Módulos

Veja a linha no topo do documento.
Ela usa o comando `#import` para importar um **módulo** do Typst.
No caso, estamos importando o pacote `quati-curriculum` na versão `0.1.0`.
Ele está disponível no Typst Universe, portanto usamos o atalho `@preview` para localizá-lo.

```typst title="main.typ" frame="code"
#import "@preview/quati-curriculum:0.1.0": (
  components.header, components.heading_icon, components.section, packages.icons.icon, packages.icons.provide-icons,
  style.theme_colors, template,
)
```

O comando `#import` pode importar pacotes do typst Universe, ou outros **arquivos** locais do seu projeto.
Para entender melhor, acesse sua [referência](https://typst.app/docs/reference/foundations/module/).

Depois do símbolo de dois-pontos (`:`), descrevemos quais **componentes** queremos importar do pacote.
Todos eles são simplesmente variáveis ou **funções** customizadas do Typst, que foram escritas pelo autor do pacote.

Por exemplo, o componente `components.header` é uma função **customizada** cuja implementação pode ser vista [nesta página](https://github.com/gabdumal/quati_curriculum/blob/main/src/components/header.typ) do seu repositório.
Outra função importada é a **`template`**, cujo código está disposto [nesta página](https://github.com/gabdumal/quati_curriculum/blob/main/src/template.typ).

Um modelo do Typst --- ou **_template_**, em inglês --- é simplesmente uma função customizada que aplicamos sobre todo o conteúdo do documento.
Para fazer isso, usamos a expressão `#show`, como visto anteriormente.

Então, fornecemos a função `template` depois da expressão `#show`.
Para **customizarmos** as suas definições iniciais, usamos a funcionalidade **`with`**.
No exemplo inicial, deixamos desativadas todas as linhas, então o modelo está seguindo as definições **padrão**.
Sinta-se livre para modificá-las como desejar.

```typst title="main.typ" frame="code"
#show: template.with(
  // You can customize the color palette.
  colors: (
    // primary: blue,
    // secondary: white,
    // dark: black,
  ),
  // You can customize the icon that is displayed at the bottom of the page.
  //   background_detail: icon(
  //     width: 20em,
  //     "tabler:trees",
  //   ),
  // If you do not want to display any icon, use this definition instead.
  //   background_detail: none
)
```

Por exemplo, experimente ativar as customizações de **cores** como a seguir.

```typst title="main.typ" frame="code"
#show: template.with(
  colors: (
    primary: blue,
    secondary: white,
    dark: black,
  ),
)
```

Isso gerará um documento como o seguinte.

A outra opção de customização é o **ícone** decorativo que fica no canto inferior direito da página.
Por padrão, é usado um ícone de duas árvores.
Experimente esse código, que usa um ícone de uma CPU.
Você pode usar qualquer ícone disponível no projeto [**Tabler icons**](https://tabler.io/icons).

```typst title="main.typ" frame="code"
#show: template.with(
  background_detail: icon(
    width: 20em,
    "tabler:cpu",
  ),
)
```

Para as próximas etapas, vamos manter as configurações **padrão** mesmo.

## Componentes

O primeiro componente que usamos nesse modelo é o **cabeçalho** do currículo.
Ele é definido pela função `#header`.
Para definir o seu primeiro **nome**, use o parâmetro `first_name`; já para definir seu sobrenome, use o `last_name`.

```typst title="main.typ" frame="code" mark={2,3}
#header(
  first_name: "Gabriel",
  last_name: "Gonçalves",
  picture: image("assets/person.jpg"),
  contact_information: (
    // ...
  )
```

Definir uma **imagem** é opcional.
Se você não quiser usar uma imagem, **defina** o atributo `picture` com o valor `none`.

```typst title="main.typ" frame="code" mark={4}
#header(
  first_name: "Gabriel",
  last_name: "Gonçalves",
  picture: none,
  contact_information: (
    // ...
  )
```

Já se você quiser, **delete** o arquivo `person.jpg` dentro da pasta `assets`.
Escolha a foto que você quer usar, e faça **upload** dela para dentro da pasta `assets`.
Finalmente, **edite** o código do cabeçalho para usar o nome da sua imagem.

```typst title="main.typ" frame="code" mark={4}
#header(
  first_name: "Gabriel",
  last_name: "Gonçalves",
  picture: image("assets/minha_imagem.png"),
  contact_information: (
    // ...
  )
```

O último parâmetro é a lista de **informações** básicas e de contato, `contact_information`.
Cada entrada na lista é um dicionário composto por três atributos.

1. `icon`: é o **ícone** decorativo, que pode ser escolhido do conjunto [Tabler Icons](https://tabler.io/icons).
1. `info`: é o **texto** que será exibido de fato ao lado do ícone.
1. `url`: é um parâmetro opcional; quando informado, ele faz com que o texto seja um **link** que aponta para este endereço.

```typst title="main.typ" frame="code"
(
  icon: "tabler:brand-linkedin",
  info: "gabrielgoncalves",
  url: "https://www.linkedin.com/in/gabrielgoncalves",
),
```

Depois de configurar o cabeçalho, podemos iniciar as **seções** de informações.
Para abrir uma seção no Typst, utilizamos o atalho do símbolo de igual (`=`), que serve para registrar um título.

Então, usamos uma função customizada chamada `#heading_icon` para incluir um **ícone** decorativo.
Por fim, podemos escrever o **nome** da seção.
O título da seção de educação fica como a seguir.

```typst title="main.typ" frame="code"
= #heading_icon("tabler:books") Educação
```

Agora, para incluir um bloco de **atividades**, usamos o componente customizado `#section`.
Ele funciona como uma **grade**, que tem duas colunas e três linhas, sendo que a célula da terceira linha ocupa ambas as colunas.

A primeira célula, nas primeira linha, é definida pelo parâmetro `r1c1`, e serve para escrever o **nome** da atividade.
No fim dessa mesma linha, a célula `r1c2` é usada para registrar o **período** de experiência.
Na linha de baixo, `r2c1` lista a **instituição**, e `r2c2` mostra a **localidade**.
Finalmente, `r3` permite descrever em mais **detalhes**.
Todos os parâmetros são opcionais.

```typst title="main.typ" frame="code"
#section(
  r1c1: "Mestrado em Ciência da Computação",
  r1c2: [2017 #sym.dash.en 2019],
  r2c1: "Universidade Estadual de Campinas (Unicamp)",
  r2c2: "Campinas, SP",
  r3: [
    - Pesquisa em algoritmos de aprendizado de máquina.
    - Desenvolvimento de projetos de software para análise de dados.
  ],
)
```

As demais seções seguem com a mesma lógica.
Você ainda pode colocar as informações diretamente no **texto**, caso ache componente `#section` complexo demais.
Por exemplo, a seção de habilidades utiliza subseções e listas.

```typst title="main.typ" frame="code"
= #heading_icon("tabler:sparkles") Habilidades

== #heading_icon("tabler:device-desktop-code") Programação

- *Linguagens de Programação:* Python, JavaScript, Java, C#sym.hash
- *Frameworks:* React, Node.js, Django, Spring Boot

== #heading_icon("tabler:tools") Ferramentas

- *Controle de Versão:* Git, GitHub, GitLab
- *Plataformas de Nuvem:* AWS, Azure, Google Cloud
- *Outras:* Docker, Kubernetes, Jenkins

== #heading_icon("tabler:language") Idiomas

- *Inglês:* Fluente. Curso #link("https://www.gov.br/mec/pt-br/mec-idiomas", "MEC Idiomas").
```
