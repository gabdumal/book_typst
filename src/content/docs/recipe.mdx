Agora que sabemos o básico do Typst, vamos escrever um documento novo.
Dessa vez, descreveremos uma receita de bolo de chocolate!

O Typst permite que um projeto tenha vários arquivos diferentes.
Esses arquivos incluem imagens, anexos, e outras páginas do documento.

## Título

A primeira coisa de que uma receita precisa é de um **título**.
No Typst, a forma de definir títulos é com o símbolo de **igual** (`=`).
Escreva o conteúdo a seguir no documento.

```typst title="main.typ" frame="code"
= Bolo de chocolate
```

Se quisermos escrever um **subtítulo**, bastaria usar dois símbolos de igual (`=`) seguidos.
Veja o exemplo.

```typst title="main.typ" frame="code"
= Bolo de chocolate
== Ingredientes
```

Para mais níveis, você pode usar mais **repetições** de `=`.
Você pode adicionar quantos níveis quiser.

```typst title="main.typ" frame="code"
= Nível 1
== Nível 2
=== Nível 3
==== Nível 4
===== Nível 5
====== Nível 6
```

Além disso, o próprio símbolo de igual (`=`) é um atalho para a **função** `#heading`.
Na [referência](https://typst.app/docs/reference/model/heading/) dessa função você pode conferir os vários parâmetros que ela possui.
Por enquanto, o mais relevante é o `level`, que indica o nível.

```typst title="main.typ" frame="code"
#heading[Bolo de chocolate]
#heading(level: 2)[Ingredientes]
```

Mas, por enquanto, vamos remover tudo isso do documento `recipe.typ` e manter **apenas** o seguinte.

```typst title="main.typ" frame="code"
= Bolo de chocolate
```

Para adicionar uma **imagem**, use a função `#image`.
Ela recebe como parâmetro principal o **caminho** em que a imagem está.
No nosso caso, ele é `/assets/bolo.jpg`.
Adicione o seguinte ao documento.

```typst title="main.typ" frame="code"
#image("assets/bolo.jpg")
```

Essa função apresenta outros **parâmetros**, como descritos em sua [referência](https://typst.app/docs/reference/visualize/image/).
Dois muito importantes são a altura (`height`) e a largura (`width`).
Essa imagem tem 1920 &times; 1280 px, então ela fica muito grande na página.

Vamos definir a **altura** como 6 centímetros, que é um tamanho mais razoável.
Perceba que a largura foi automaticamente ajustada para ficar proporcional.

```typst title="main.typ" frame="code"
#image(
  "assets/bolo.jpg",
  height: 6cm
)
```

Se quisermos fazer um banner, podemos fazer a imagem ocupar a **largura completa** da página, dentro das margens.
Para isso, use um valor de porcentagem no parâmetro `width`.

```typst title="main.typ" frame="code"
#image(
  "assets/bolo.jpg",
  height: 6cm,
  width: 100%
)
```

Por padrão, a imagem é cortada para se **ajustar** às proporções customizadas.
Se preferir que a imagem seja esticada em vez de cortada, você pode usar o parâmetro `fit` com o valor `stretch`.

```typst title="main.typ" frame="code"
#image(
  "assets/bolo.jpg",
  height: 6cm,
  width: 100%,
  fit: "stretch"
)
```

Por enquanto, vamos manter apenas a forma mais **simples** de inclusão de imagem.
Apague os experimentos que fizemos.

```typst title="main.typ" frame="code"
#image("assets/bolo.jpg")
```
