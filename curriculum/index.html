Currículo

Construímos um documento inteiro do zero, e customizamos seu estilo da maneira como quisemos.

Mas um dos pontos-chave do Typst é sua capacidade de usar modelos de documentos prontos, que já carregam toda a formatação necessária.

Modelo

Seção intitulada “Modelo”

Neste capítulo, criaremos um documento baseado em um modelo de currículo, e editaremos seus campos. Acesse a página Typst Universe. Ela lista todos os pacotes e modelos disponíveis.

O modelo que usaremos é chamado quati-curriculum, e sua página pode ser acessada por este link. Ele permite customizar a fonte, as cores, e os ícones usados.

Acesse a página do modelo. Na lateral direita, você verá o botão “Create project in app”. Clique nele para criar um documento que utiliza esse modelo.

Isso abrirá uma nova página para que você confirme a criação do documento. Na lateral direita, existe um campo de texto, em que você deve escrever o nome Meu currículo. Então, pressione o botão “Create”.

Então, o Typst criará o documento e abrirá sua página de edição e de renderização.

Ícones

Seção intitulada “Ícones”

Esse modelo requer uma configuração a mais para funcionar devidamente, como descrito pela mensagem no documento. Devido à licença de propriedade intelectual, o conjunto de ícones não pode ser distribuído junto com o modelo.

Portanto, acesse este link para escolher o pacote de ícones. Esse site fornece várias opções de estilos de arte. O que vamos usar se chama tabler. Pesquise por ele na página e clique no botão de download. Isso vai baixar o arquivo tabler.json.

Abra o menu de explorar arquivos do web app do Typst. Dentro da pasta assets, você verá que já existe um arquivo tabler.json. Ele é apenas um exemplo vazio, que não carrega os ícones reais.

Apague todo o conteúdo desse arquivo assets/tabler.json.

Então, copie o conteúdo do arquivo tabler.json que baixamos, e cole no arquivo assets/tabler.json que está no Typst.

Agora, abra novamente o arquivo main.typ no menu de explorar arquivos. Selecione todo o bloco de texto declarado pelo componente #block, que instrui como configurar o pacote de ícones, e então apague-o.

Isso fará com que o currículo seja efetivamente renderizado como primeira página do documento.

Módulos

Seção intitulada “Módulos”

Veja a linha no topo do documento. Ela usa o comando #import para importar um módulo do Typst. No caso, estamos importando o pacote quati-curriculum na versão 0.1.0. Ele está disponível no Typst Universe, portanto usamos o atalho @preview para localizá-lo.

O comando #import pode importar pacotes do typst Universe, ou outros arquivos locais do seu projeto. Para entender melhor, acesse sua referência.

Depois do símbolo de dois-pontos (:), descrevemos quais componentes queremos importar do pacote. Todos eles são simplesmente variáveis ou funções customizadas do Typst, que foram escritas pelo autor do pacote.

Por exemplo, o componente components.header é uma função customizada cuja implementação pode ser vista nesta página do seu repositório. Outra função importada é a template, cujo código está disposto nesta página.

Um modelo do Typst — ou template, em inglês — é simplesmente uma função customizada que aplicamos sobre todo o conteúdo do documento. Para fazer isso, usamos a expressão #show, como visto anteriormente.

Então, fornecemos a função template depois da expressão #show. Para customizarmos as suas definições iniciais, usamos a funcionalidade with. No exemplo inicial, deixamos desativadas todas as linhas, então o modelo está seguindo as definições padrão. Sinta-se livre para modificá-las como desejar.

A outra opção de customização é o ícone decorativo que fica no canto inferior direito da página. Por padrão, é usado um ícone de duas árvores. Experimente esse código, que usa um ícone de uma CPU. Você pode usar qualquer ícone disponível no projeto Tabler icons.

Para as próximas etapas, vamos manter as configurações padrão mesmo.

Componentes

Seção intitulada “Componentes”

O primeiro componente que usamos nesse modelo é o cabeçalho do currículo. Ele é definido pela função #header. Para definir o seu primeiro nome, use o parâmetro first_name; já para definir seu sobrenome, use o last_name.

Definir uma imagem é opcional. Se você não quiser usar uma imagem, defina o atributo picture com o valor none.

Já se você quiser, delete o arquivo person.jpg dentro da pasta assets. Escolha a foto que você quer usar, e faça upload dela para dentro da pasta assets. Finalmente, edite o código do cabeçalho para usar o nome da sua imagem.

O último parâmetro é a lista de informações básicas e de contato, contact_information. Cada entrada na lista é um dicionário composto por três atributos.

  1. icon: é o ícone decorativo, que pode ser escolhido do conjunto Tabler Icons.
  2. info: é o texto que será exibido de fato ao lado do ícone.
  3. url: é um parâmetro opcional; quando informado, ele faz com que o texto seja um link que aponta para este endereço.

Depois de configurar o cabeçalho, podemos iniciar as seções de informações. Para abrir uma seção no Typst, utilizamos o atalho do símbolo de igual (=), que serve para registrar um título.

Então, usamos uma função customizada chamada #heading_icon para incluir um ícone decorativo. Por fim, podemos escrever o nome da seção. O título da seção de educação fica como a seguir.

Agora, para incluir um bloco de atividades, usamos o componente customizado #section. Ele funciona como uma grade, que tem duas colunas e três linhas, sendo que a célula da terceira linha ocupa ambas as colunas.

A primeira célula, nas primeira linha, é definida pelo parâmetro r1c1, e serve para escrever o nome da atividade. No fim dessa mesma linha, a célula r1c2 é usada para registrar o período de experiência. Na linha de baixo, r2c1 lista a instituição, e r2c2 mostra a localidade. Finalmente, r3 permite descrever em mais detalhes. Todos os parâmetros são opcionais.

As demais seções seguem com a mesma lógica. Você ainda pode colocar as informações diretamente no texto, caso ache componente #section complexo demais. Por exemplo, a seção de habilidades utiliza subseções e listas.
